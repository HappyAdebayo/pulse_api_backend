# pulse_api Setup

This is a Node.js backend generated by [Backly](https://backly.app).

## Installation
```bash
npm install
```

## Environment Variables
1. Create a `.env` file in the root directory (one has been pre-generated for you).
2. Configure your database and Redis credentials.

## Database Setup

> [!IMPORTANT]
> Before running migrations, you MUST manually create the database in your database instance.

1. **Create the Database**
   Open your SQL client (like pgAdmin, DBeaver, or psql) and run:
   ```sql
   CREATE DATABASE pulse_api;
   ```

2. **Run Migrations**
   Once the database is created, run the following command to create the tables:
   ```bash
   npx sequelize-cli db:migrate
   ```

## Start Server

### Development
```bash
npm run dev
```

### Production
```bash
npm start
```

## Making Requests
By default, the API is accessible via the `/api` prefix.

### **Development**
If you are running the server using:
```bash
npm run dev
```
Your requests should be made to:
- **URL**: `http://localhost:3000/api/{route}`
- **Example**: `GET http://localhost:3000/api/users`

### **Documentation**
A full Swagger/OpenAPI interactive documentation is available at:
`http://localhost:3000/api-docs`

### **Authentication**
For protected endpoints, include the JWT token in the header:
```
Authorization: Bearer <your_jwt_token>
```

## Project Structure
- `controllers/`: Your custom controller logic.
- `models/`: Sequelize models.
- `services/`: Business logic and workflows.
- `routes/`: Express route definitions.
- `migrations/`: Database schema versioning.
- `.backly/`: Generated base classes (Do not edit directly).
